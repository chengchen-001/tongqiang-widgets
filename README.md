# tongqiang-widgets
痛墙 · 组件库（公开）：应用内可导入的组件包清单与素材

痛墙 App 里「更多 → 组件库 → 已导入」读的就是这个仓库的 `widgets.json`。

## 加一个自己的组件

在 `widgets.json` 的 `items` 里加一条即可，`assets/` 里放素材（`bg` / `sticker` 字段写相对路径）：

```json
{
  "id": "my-widget",
  "name": "组件名字",
  "desc": "一句话说明它干什么",
  "size": "2x1",
  "bgColor": "#FF26262B",
  "text": "一行字",
  "textScale": 0.16,
  "textColor": "#FFFFFFFF",
  "textPos": "bc"
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，同名会被覆盖 |
| `size` | 建议尺寸：`1x1` / `1x2` / `2x1` / `2x4` / `3x2`（用户仍可在桌面上自由拉伸） |
| `bgColor` | 没有背景图时铺的底色 |
| `bg` / `sticker` | 相对 `assets/` 的路径，可省略 |
| `textPos` | 文字落位：`tl`/`tc`/`tr`/`ml`/`c`/`mr`/`bl`/`bc`/`br` |
| `daily` | **每日轮换文案池**（可选）。填了它，组件每天自动换一句话 —— 见下 |

## `daily`：每天换一句

`daily` 可以写数组，也可以只写一个字符串：

```json
"daily": ["红烧肉", "番茄炒蛋", "糖醋排骨"]
```

App 会按**当天日期**从池子里取一条显示。同一天内反复刷新是同一句（不会每次重画都跳），
换一天才换。

用途是那些「一天一个值」的东西 —— 今天吃什么、今天星期几、今天宜/忌。

注意：
- 同一天内不重画就不会变。App 每天零点会重画一次；万一零点闹钟被手机系统掐了，
  **打开一次痛墙就会补画**，所以不会被卡在昨天那道菜。
- `text` 在有 `daily` 时只作兜底，正常不会显示。

## 关于素材

- 背景图建议长边 1024px 以内，贴纸建议透明 PNG
- 组件会在桌面被自由拉伸，位图按实测槽位比例实时重算，不用为不同尺寸准备多套图
